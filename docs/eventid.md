# Getting the EventId

## Initial steps

1. Visit the website of the active event on the livetiming website
2. In the url you will find a piece of text containing the EventId". <br>
![EventID](/assets/EVENTID.png)
1. Copy the numeric value and paste it in  `AZURE_EVENTID` found in the .env file.


#### Without a EventId value, The livetiming connector might fail to connect.
